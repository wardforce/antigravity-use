# README 错别字修订执行方案

## 编排判断

该任务只包含一次可验收的机械文本修订，不满足 `agy-orchestrator` 要求的“至少两个具有独立结果和验收条件的步骤”。因此由主模型直接完成，不调用 `agy`，也不运行 `agy models`。

## 执行步骤

1. 读取仓库指令并记录当前分支、`git status --short`、已有 diff 和未跟踪文件，保存用户原有改动基线。
2. 定位目标 `README`，读取错别字所在上下文并确认唯一的“原文 → 正确文本”替换；若存在多个候选 README 或无法唯一确认错字，则先请求用户指定，不猜测。
3. 使用最小补丁只替换该处错别字，保持文件编码、换行、排版及其他内容不变。
4. 由主模型亲自检查目标文件完整 diff，确认相对基线仅新增预期的一处文字变化；重新读取修改后的上下文，并搜索原错字，验证修订生效且未误替换。
5. 交付时报告目标文件、具体替换和实际校验结果，同时确认用户原有改动保持完整。

## 本轮边界

本轮只输出执行方案，不执行上述修订，不修改任何 README 或其他项目文件。
