# README 错别字修订执行方案

## 编排判断

这是一个单文件、单处文本替换的简单任务，没有可并行的独立子任务，也不存在需要跨模型协调的依赖链。`agy-orchestrator` 应将它路由为主模型本地一步执行，不启动 AGY 委派，避免让编排成本超过修改本身。

## 执行步骤

1. 只读检查仓库状态并定位目标 `README` 文件，同时记录现有未提交改动；不暂存、不重置、不覆盖用户已有修改。
2. 读取目标位置的上下文，确认错别字、正确写法及替换范围。若仓库内有多个 `README`，先依据任务上下文锁定唯一目标；若仍不唯一，则暂停并请用户指定文件。若找不到可确认的错别字，也暂停而不猜测修改。
3. 使用最小补丁仅替换该处错别字，不调整排版、换行、编码或无关措辞。
4. 查看目标文件的精确 diff，验证只有预期的一处文本变化；随后重新搜索原错字，并读取修改后的上下文，确认正确写法已生效且没有误替换。
5. 最终报告目标文件、原文与修订文本，以及 diff 校验结果；不以编排器或执行器的自报成功代替主模型验收。

## 本轮边界

本轮只产出方案，不执行上述步骤，不修改任何 `README` 或其他项目文件。
